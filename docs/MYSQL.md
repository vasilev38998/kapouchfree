# MySQL на Beget

На production-хостинге создайте отдельную базу и пользователя MySQL, затем импортируйте `database/schema.sql` через phpMyAdmin или консольный клиент.

Переменные окружения приложения:

```text
DB_HOST=localhost
DB_PORT=3306
DB_NAME=...
DB_USER=...
DB_PASSWORD=...
DB_POOL_SIZE=4
```

Для виртуального хостинга пул намеренно небольшой. Значение `DB_POOL_SIZE=4` — стартовая настройка; при реальной нагрузке её нужно сверить с лимитами тарифа Beget и количеством Passenger-процессов.

Схема уже содержит основные сущности соцсети: пользователей, сессии, OTP, подписки, посты, комментарии, реакции, диалоги, участников диалогов, сообщения, уведомления и realtime events.

Следующий шаг миграции backend: заменить in-memory `sessions`, `otpStore` и event-buffer на эти таблицы. После этого перезапуск Passenger не будет разлогинивать пользователей и терять события.
