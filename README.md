# КофеФинансы

Статический финансовый кабинет для небольшой кофейни. Работает полностью в браузере, не требует базы данных или серверного языка и подходит для обычного shared-хостинга Beget.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 8080
```

Данные сохраняются в `localStorage` текущего браузера. Для резервного копирования используйте экспорт JSON в интерфейсе.

## Публикация на Beget

Загрузите `index.html`, `styles.css` и `app.js` в каталог `public_html` вашего домена. Сборка и настройка PHP не нужны.
